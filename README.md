# Slides

A PowerPoint-style presentation editor that runs in the browser.

**Live:** https://orhava.github.io/office-slides/

## Features
- Drag, resize, rotate objects; multi-select (Shift), arrow-key nudge, snap-to-grid, group/ungroup, align & distribute, z-order
- Text boxes with rich formatting (fonts, sizes, color, bold/italic/underline, bullets, RTL), shapes (10 types incl. arrows & callouts), lines with arrowheads, images (upload, drag-drop, paste), tables, bar/line/pie charts
- 9 slide layouts, 6 themes, per-slide background, slide transitions, per-object click animations
- Speaker notes, **presenter view** (next slide, notes, clock), laser pointer (L), blank screen (B), jump to slide by number
- Filmstrip with drag-to-reorder, context menus, undo/redo, keyboard shortcuts (Ctrl+M new slide, Ctrl+D duplicate, Ctrl+G group, F5 present)
- Autosaves in the browser; multiple presentations
- Export to **PowerPoint (.pptx)** with editable text, shapes, tables, native charts and notes; PDF via print; PNG of a slide; standalone HTML slideshow; save/open project JSON
